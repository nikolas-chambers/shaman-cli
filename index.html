shaman

A coding agent for your terminal

One native C++ binary for any model provider, or a local model. Reads, edits, runs and verifies your code.

Get started View on GitHub 
$ shaman                              # full-screen UI
$ shaman run "why is the build failing?"
$ git diff | shaman run "review this"
$ shaman web                          # browser UI

Everything in one binary

Starts in milliseconds, no runtime to install.

Any model

OpenCode Zen, Anthropic, OpenAI, Gemini, OpenRouter, Groq, Together, Hugging Face and 20 more with your key; free GitHub Models through your GitHub login; Azure, Vertex and Bedrock; or Ollama and LM Studio locally.

Tuned per model

Reasoning effort you can change live, temperature, extra request fields, tool sets and context budgets for small or cheap models. Thinking survives tool calls.

Terminal, web, desktop, editor

A full-screen TUI, a browser UI and desktop app running several sessions at once, a VS Code extension, plus an HTTP API and ACP for Zed. Inline diffs, revert and fork everywhere.

Safe by default

Edits and commands ask first. Accept-edits and plan modes with plan approval, an OS sandbox for shell commands, secrets redacted, a loop guard, undo outside git.

Hooks

Your scripts run before and after tools, on every prompt and when the agent wants to stop. Block a command, format a file, or insist the tests pass first.

28 tools, 35 skills

Edit, patch, grep, a codebase symbol index, background jobs, web search, notebooks, images, language servers, memory and subagents. Skills from code review to Kubernetes, SQL and Office documents.

Portable

Drop a shaman.ini next to the binary and everything lives beside it: keys, settings, sessions. Run it from a USB stick; upgrades replace only the binary.

Make it yours

Themes for terminal and browser, from dark and light to Halloween, Dracula and Nord. Custom keybinds, a statusline command, custom agents, commands and skills.

Extensible

MCP servers with tools, prompts and resources (stdio, HTTP, OAuth), plugins in any language with Python and TypeScript SDKs.

Works while you're away

/goal keeps going until it's verified done, background agents run in parallel, notifications tell you when, and cron runs it on a schedule.

Easy to debug

Per-subsystem debug logs, full JSONL traces, /context and shaman doctor, and shaman debug to inspect prompts, models and permissions.

Everywhere

Linux, macOS, Windows and Android (Termux), or any browser on your network. A native Android chat app is coming soon.

See it work

One question, in the browser and in the terminal, in a few of the themes.

Runs where you work

One codebase, native on every platform.

Linux

x64 and arm64 release zips (CLI, plus the desktop app on x64), or build from source on any distribution.

macOS

Apple silicon and Intel: the CLI and a native Shaman.app. Notifications, clipboard and a sandbox-exec shell sandbox built in.

Windows

Windows 10 and 11: shaman.exe and a native desktop app on WebView2.

Android: Termux

An aarch64 release zip for Termux, or one script that builds and installs it, with notifications and links through Termux:API.

Android app coming soon

A native chat app for your phone, talking to shaman on the device or on your computer.

Any browser

shaman web serves the full UI; add --host and --token to use it from another device.

Install

One line on Linux, macOS and Termux, or PowerShell on Windows. Release zips and source builds work too.

$ curl -fsSL https://raw.githubusercontent.com/nikolas-chambers/shaman-cli/main/scripts/install.sh | sh
PS> irm https://raw.githubusercontent.com/nikolas-chambers/shaman-cli/main/scripts/install.ps1 | iex

Or build from source:

# Debian/Ubuntu: apt install cmake ninja-build libcurl4-openssl-dev libssl-dev nlohmann-json3-dev
# macOS:         brew install cmake ninja curl openssl nlohmann-json
$ git clone https://github.com/nikolas-chambers/shaman-cli
$ cd shaman-cli && cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
$ cmake --build build && sudo cmake --install build
